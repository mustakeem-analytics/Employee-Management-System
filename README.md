# Employee-Management-System
Python and Sql based Employee Management-System
A console-based Employee Management System developed using Python and MySQL to manage employee records efficiently.

Features

Add Employee

Display Employee Records

Update Employee Information

Promote Employee / Increase Salary

Search Employee

Remove Employee

Input Validation

Error Handling

MySQL Database Integration

Technologies Used

Python

MySQL

SQL

Object-Oriented Programming (OOP)

mysql-connector-python

Project Structure

Employee-Management-System/
│
├── employee_management_system.py
├── README.md

└── .gitignore

Database

The application uses a MySQL database named employee with an empdata table to store employee information such as Employee ID, Name, Email, Phone, Address, Post, and Salary.

How to Run

Install Python.

Install the required package:

pip install -r requirements.txt

Create the MySQL database and table.

Configure the database connection using environment variables.

Run the application:

python employee_management_system.py
